# 图标文件说明

应用打包需要以下图标文件：

## Windows
- 文件名: `icon.ico`
- 尺寸: 256x256 像素
- 格式: ICO 格式

## macOS
- 文件名: `icon.icns`
- 尺寸: 512x512 像素
- 格式: ICNS 格式

## Linux
- 文件名: `icon.png`
- 尺寸: 512x512 像素
- 格式: PNG 格式

## 注意事项

如果没有提供图标文件，打包时会使用默认图标。

建议使用专业的图标设计工具制作，或者在线生成工具：
- https://icoconvert.com/
- https://iconifier.net/
